# Telecom Customer Churn Analysis Dashboard

## Overview

The **Telecom Customer Churn Analysis Dashboard** is an interactive **Power BI data analytics project** designed to analyze customer churn patterns and identify high-risk customer segments.

The dashboard analyzes **7,043 telecom customers** across customer demographics, contract types, services, payment methods, tenure and billing information. It uses **Power Query** for data transformation and **DAX** for dynamic KPIs and analytical measures.

## Objectives

* Analyze overall customer churn and retention.
* Identify customer segments with higher churn risk.
* Compare churn across different contract types.
* Analyze the relationship between customer tenure and churn.
* Understand churn patterns across services and payment methods.
* Monitor customer count, churn rate and billing-related KPIs.
* Present insights through an interactive dashboard.

## Key Insights

* **Total Customers:** 7,043
* **Overall Churn Rate:** 26.54%
* **Month-to-Month Customer Churn:** 42.71%
* Month-to-month customers represent a significantly higher-risk segment compared with the overall customer base.
* Contract type, services, payment methods and customer demographics provide useful indicators for understanding churn behavior.

## Dashboard Features

### KPI Analysis

The dashboard provides dynamic KPIs for:

### Interactive Filtering

Users can interact with the dashboard using Power BI filters and slicers to analyze specific customer segments and compare churn patterns.

## Business Value

The analysis can help a telecom business identify customers who are more likely to churn and understand the characteristics of high-risk segments.

The **42.71% churn rate among month-to-month customers**, compared with the **26.54% overall churn rate**, highlights an important segment for customer-retention strategies.
